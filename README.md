# WindLens

Day-ahead wind forecast analysis for Great Britain using Elexon FUELHH and WINDFOR.

The product will show which forecast was available at a procurement decision cutoff and evaluate its historical error. National generation data alone cannot determine a utility's procurement requirement.

## Project status

Research and data validation are in progress. This repository does not yet contain a runnable web application or a deployed service.

## AI assistance

AI tools are being used for research, data inspection, implementation suggestions, and review. Validation evidence and design decisions will be documented as the project develops. This disclosure does not imply that the candidate has independently reviewed work they have not yet reviewed.
